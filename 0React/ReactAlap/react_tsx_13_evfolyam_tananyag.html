React fejlesztés TypeScripttel (TSX)

A professzionális szoftverfejlesztésben ma már alapkövetelmény a típusbiztos frontend kódolás. Ez az interaktív útmutató megmutatja a Vite-alapú TSX környezet beállítását, a generált fájlrendszer anatómiáját és a fordítási idejű típusellenőrzés előnyeit.

Build Tool Vite 5+
Dialektus TypeScript + TSX
Követelmény Node.js LTS
Architektúra Vite Single Page (SPA)

01 Projekt Létrehozása és Futtatása

Másold ki a parancsokat, vagy kattints a kártyákra a magyarázatukhoz!

1. Lépés Inicializálás

Vite React-TS sablon létrehozása

Létrehozza a tiszta TSX projektmappát a legfrissebb React és TypeScript csomagokkal.

npm create vite@latest react-ts-alapok -- --template react-ts
2. Lépés Függőségek

Csomagok letöltése

Lépj be a létrehozott könyvtárba, majd telepítsd a `node_modules` elemeit a package.json alapján.

cd react-ts-alapok && npm install
3. Lépés Fejlesztés

Dev Server futtatása (HMR)

Elindítja a helyi Vite szervert szupergyors Hot Module Replacement (HMR) támogatással.

npm run dev

Típusdeklaráció

A `.d.ts` (declaration) fájlok csak típusokat tartalmaznak, futtatható JavaScript kóddá nem fordulnak. Ez a fájl mondja meg a TypeScriptnek, hogy miként kell kezelni az importált SVG, PNG vagy CSS fájlokat hibajelzés nélkül.

FORRÁSKÓD 
/// <reference types="vite/client" />

// Ez teszi lehetővé a médiafájlok és környezeti változók (import.meta.env)
// típusbiztos elérését.
💡
Technikusi szakmai megjegyzés: Enélkül az `import reactLogo from "./assets/react.svg"` sor piros hibát dobna a VS Code-ban.
